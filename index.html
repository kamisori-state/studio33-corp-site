サービス

パソコンまわりのことなら、なんでも。

「これは頼んでいいのかな？」と迷う内容も、まずはお聞かせください。

初期設定・セットアップ

新しいパソコンの初期設定から、メール・プリンター・よく使うソフトの準備まで。届いたその日から使える状態にします。

トラブル対応

起動しない、動作が遅い、エラーが出る。原因を調べて、状況に合った直し方をご提案します。

データ移行・バックアップ

写真や書類、メールを新しいパソコンへ。大切なデータを守るバックアップの仕組みも整えます。

ネットワーク・Wi-Fi

つながらない、遅い、すぐ切れる。ルーターの設定や置き場所まで見直して、快適な通信環境に。

セキュリティ対策

ウイルス対策、パスワードの管理、怪しいメールへの備え。安心して使える設定をご提案します。

使い方のご相談

基本操作から仕事で使うソフトまで。お客さまのペースに合わせて、分かるまでご説明します。

「こんなこと聞いていいのかな」も、大歓迎です。

スタッフより

パソコンは、
もっと気軽に頼っていい。

パソコンの不調は、仕事や暮らしを思った以上に止めてしまいます。それなのに「こんなことで頼むのは悪いかな」と、ひとりで悩んでいる方がたくさんいます。

Studio33 は、そんな小さな「困った」をいちばんに受け止める窓口でありたいと考えています。どうぞ気軽に声をかけてください。

当社が使用するアプリについて

当社は、サービスのご案内動画を公式YouTubeチャンネルで発信するため、社内用のショート動画作成・投稿ツール「Short movie」を使用しています。このツールは、写真と文章から縦型のショート動画とBGMを作成し、YouTube Data API を通じて当社のYouTubeチャンネルへ投稿します。Googleアカウントの情報は動画の投稿と投稿結果の確認にのみ使用し、それ以外の目的には使いません。詳しくはプライバシーポリシーと利用規約をご覧ください。

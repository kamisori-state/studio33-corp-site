世田谷区のパソコンサポート

パソコンの「困った」に、
まるごとお応えします。

設定がわからない、急に動かなくなった、新しいパソコンにデータを移したい。Studio33 は、ご家庭や小さな事業所のパソコンまわりのお悩みを、世田谷区を中心にサポートしています。

まずはご相談ください

サービス

初期設定・セットアップ

新しいパソコンの初期設定、メールやプリンターの設定、よく使うソフトの導入をお手伝いします。

トラブル対応

起動しない、動作が遅い、エラーが出るなどの不調を調べ、原因に合わせて対処します。

データ移行・バックアップ

古いパソコンから新しいパソコンへの写真や書類の引っ越し、大切なデータのバックアップ体制づくりを行います。

ネットワーク・Wi-Fi

インターネットにつながらない、Wi-Fiが不安定といったお悩みの調査と設定を行います。

セキュリティ対策

ウイルス対策、パスワードの管理、怪しいメールへの備えなど、安心して使うための設定をご提案します。

使い方のご相談

基本操作から仕事で使うソフトまで、お客さまのペースに合わせてご説明します。

対応エリア

東京都世田谷区を中心に対応しています。区外の方もお気軽にご相談ください。

当社が使用するアプリについて

当社は、サービスのご案内動画を公式YouTubeチャンネルで発信するため、社内用のショート動画作成・投稿ツール「Short movie」を使用しています。このツールは、写真と文章から縦型のショート動画とBGMを作成し、YouTube Data API を通じて当社のYouTubeチャンネルへ投稿します。Googleアカウントの情報は動画の投稿と投稿結果の確認にのみ使用し、それ以外の目的には使いません。詳しくはプライバシーポリシーと利用規約をご覧ください。

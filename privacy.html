プライバシーポリシー

制定日: 2026年10月18日

Studio33（以下「当社」）は、ショート動画の作成・投稿ツール「Short movie」（以下「本ツール」）における利用者情報の取り扱いを、次のとおり定めます。

1. 取得する情報

本ツールは、Googleアカウントでの認可を通じて、次の情報にアクセスします。

  • YouTubeチャンネルの基本情報（チャンネルID、チャンネル名）
  • 本ツールで投稿した動画の状態（処理状況、公開設定）
  • Googleが発行するアクセストークンおよびリフレッシュトークン

利用する権限（スコープ）は次の2つです。

  • https://www.googleapis.com/auth/youtube.upload（動画のアップロード）
  • https://www.googleapis.com/auth/youtube.readonly（チャンネル情報と投稿した動画の状態の確認）

メールアドレス、連絡先、視聴履歴、ほかの動画、コメントなどにはアクセスしません。

2. 利用目的

取得した情報は、利用者が指示した動画を利用者自身のYouTubeチャンネルへ投稿すること、および投稿結果を確認することにのみ使います。広告、分析、機械学習モデルの学習には使いません。

3. 保存場所と保存期間

トークンと投稿履歴（動画ID、題名、投稿日時、ファイルの識別値）は、本ツールを実行するパソコン内にのみ保存します。当社のサーバーや第三者のサーバーには送信しません。利用者が認可を取り消すか、本ツールのログアウト機能を実行すると、トークンは削除されます。

4. 第三者への提供

取得した情報を第三者に販売・提供・共有することはありません。ただし、動画の投稿のためにGoogle（YouTube）へ動画と題名などの情報を送信します。

5. Google API サービスのユーザーデータに関するポリシーの遵守

本ツールによるGoogle APIから受け取った情報の利用および他のアプリへの転送は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

6. 認可の取り消し

利用者はいつでも、Googleアカウントのサードパーティ アクセス設定から本ツールへの許可を取り消せます。YouTubeの利用にあたってはYouTube 利用規約とGoogle プライバシーポリシーが適用されます。

7. 改定

本ポリシーを改定する場合は、このページで公表します。
